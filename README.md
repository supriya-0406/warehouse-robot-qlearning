# 🤖 Warehouse Robot Path Optimization using Q-Learning

## 📌 Overview

This project uses Q-Learning, a reinforcement learning algorithm, to train a warehouse robot to find the optimal path.

---

## 🎯 Objective

Optimize robot movement using reward-based learning.

---

## 🧠 Model

Q-Learning

---

## ⚙️ Technologies

* Python
* NumPy

---

## 🚀 How to Run

pip install -r requirements.txt
python main.py

---

## 📈 Output

* Learned Q-table
* Optimal navigation path

---

## 💡 Business Impact

* Warehouse automation
* Reduced delivery time
* Efficient path planning

## 🎯 Learning Outcomes
